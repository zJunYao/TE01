## 快速防误用

1. Unity 工程是 `UnityProject`，配置源在仓库 `Configs/GameConfig`。
2. 业务通过 `GameModule` 访问服务；`UI` 是业务单例，不是 `IUIModule`。
3. `ShowUIAsync` 返回 `void`；需要等待时用 `ShowUIAsyncAwait`，但要看其当前实现限制。
4. UI 隐藏不解绑事件；关闭才走销毁清理，默认隐藏约十秒后关闭。
5. 普通 Asset 成功加载与 `UnloadAsset` 配对；实例资源优先 `LoadGameObjectAsync`，实例销毁时自动归还源资源引用。
6. `SetSprite` 返回 `void`，不虚构 `SetSpriteAsync` 或 `ReleaseSprite`。
7. 当前 `lazyload` 是按表懒加载，不能据技能文档断言分片导出已经实现。
8. 编译通过不等于启动、自动化门禁、热更或打包通过。
