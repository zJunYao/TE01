# 特效资源分类与使用

本目录存放可独立复用的特效。本次建立以下约定，既有其他资源不做批量迁移。

## 分类与命名

- 路径按用途、对象类别、具体对象组织，例如`Combat/Enemy/Mold/`。
- 每个分类下使用`Prefabs/`、`Materials/`、`Textures/`，需要时再增加其他资源类型目录。
- 预制体使用`FX_对象_行为`，材质使用`M_对象_用途`，纹理使用`T_对象_用途`；资产名称保持唯一。
- 原始图像处理脚本和产物保留在仓库根`素材/`，Unity运行资源放在本目录。
- 迁移使用Unity资产数据库保留GUID；不直接修改预制体、场景YAML或meta。

## 霉菌爆散

- 入口：`Combat/Enemy/Mold/Prefabs/FX_Mold_Burst.prefab`。
- 根节点归一变换，包含粒子系统和`MoldBurstEffect`；不依赖Animator，不持有资源加载句柄。
- 独立实例启用时自动播放。粒子系统Play On Awake关闭，Emission配置时间0的一次18枚Burst；支持Prefab编辑页面的Play/Restart原生预览，不依赖脚本发射。
- `Play()`先清空再播放，`Clear()`停止并清空，禁用时自动清空。播放结束不销毁或隐藏对象，回收由调用方负责。
- 怪物预制体使用名为`Burst`的嵌套实例，关闭该实例的启用自动播放，由怪物驱动按受击动画时序触发。
- 数量在Emission/Bursts配置，二维发散在Shape/Circle配置，速度、寿命、尺寸、颜色与初始旋转在Main配置；自旋、渐缩、淡出、阻尼和排序也由粒子模块管理。播放组件不生成粒子、不持有表现参数。
- 当前独立预制体不包含怪物受击挤压和本体隐藏，这部分仍属于角色动画。
- 正式业务按项目资源API加载GameObject并管理生命周期；本次嵌套引用不新增动态加载和打包设置。
