# 配置与编辑器工具

核实日期：2026-10-26；这里只记录静态入口，没有执行导出、资源生成、平台切换或构建。

## Luban 当前真实链路

来源：[配置根目录](../../Configs/GameConfig/)、[配置注册](../../Configs/GameConfig/luban.conf)、[加载器模板](../../Configs/GameConfig/CustomTemplate/ConfigSystem.cs)、[懒加载模板](../../Configs/GameConfig/CustomTemplate/CustomTemplate_Client_LazyLoad/cs-bin/tables.sbn)。

- `Defines` 放结构定义；`Datas` 放 Excel，`__tables__.xlsx/__beans__.xlsx/__enums__.xlsx` 参与注册。不能只看文件名推断客户端/服务端字段范围。
- `luban.conf` 的客户端 target 使用组 c、命名空间 `GameConfig`、管理器 `Tables`，服务端使用组 s；具体语法与数据约束以本地 Luban 版本和真实校验为准。
- 导出执行 `Tools/Luban/Luban.dll`；客户端代码目标 `UnityProject/Assets/GameScripts/HotFix/GameProto/GameConfig/`，二进制目标 `UnityProject/Assets/AssetRaw/Configs/bytes/`。
- 脚本先复制 `ConfigSystem.cs/ExternalTypeUtil.cs` 到 GameProto。修改加载器要回到模板；不要只修生成副本。
- `gen_code_bin_to_project_lazyload.bat` 使用 `-c cs-bin -d bin` 加自定义模板；普通客户端脚本同样用 bin，但不指定这个懒加载模板。
- 当前懒加载模板在表属性首次访问时调用 loader，构造表后 `ResolveRef(this)`，不等于每行按需加载，也不等于磁盘分片。
- 当前 ConfigSystem 首次访问 Tables 时 Load；同步加载 TextAsset 后构造 ByteBuf，没有显式空检查和 `UnloadAsset` 配对。生命周期修改需同步考虑模板、产物与加载引用，不在本次学习中修复。
- 本次检查时 GameProto 下只有 LubanLib 基础类，没有生成的 GameConfig 表类或 ConfigSystem；不能把模板存在当作配置系统已经初始化运行。

## 与技能文档的关键差异

技能参考写有 `bin-sharded`、`dataExporter=sharded`、`ClearPartitions` 等分片说明，但当前脚本/模板不具备这些特征；`CustomTemplate/SHARDED_TABLES.md` 也缺失。应视为文档/工作流与当前配置源不匹配，不能悄悄用普通导出宣称分片验收通过。

按规范修改前先确认表、主键、字段、引用、目标组和兼容性；helper 只辅助，实际 Luban 类型/引用校验与隔离产物更权威。生产导出可能覆盖生成代码和 bytes，需先预览与确认，不自动安装 openpyxl 等依赖。

## 编辑器入口

- [LubanTools](../../UnityProject/Assets/TEngine/Editor/LubanTools/LubanTools.cs)：`TEngine/Luban/转表`，实际调用 lazyload 脚本，不是只读检查。
- [UI 自动绑定](../../UnityProject/Assets/Editor/UIScriptGenerator/)：按命名/正则规则生成字段、查找绑定与可选监听，支持 UGUI/TMP；配置风格包括下划线和 m_，以 ScriptGeneratorSetting 为准。界面生成区域会重写，不把业务逻辑放到生成区。
- [图集工具](../../UnityProject/Assets/TEngine/Editor/AtlasMakerEditor/)、[图集引用分析](../../UnityProject/Assets/Editor/AtlasRefWindow/)、[资源引用分析](../../UnityProject/Assets/Editor/ReferenceFinder/)：维护/分析图集和引用，涉及 importer、资产生成时须遵循 Unity 写入边界。
- [设置面板](../../UnityProject/Assets/Editor/TEngineSettingsProvider/)、[工具栏](../../UnityProject/Assets/Editor/ToolbarExtender/)：运行模式、启动场景、更新/UI 设置的编辑入口；不是无副作用查询命令。

## 热更、打包与发布

来源：[BuildDLLCommand](../../UnityProject/Assets/TEngine/Editor/HybridCLR/BuildDLLCommand.cs)、[ReleaseTools](../../UnityProject/Assets/TEngine/Editor/ReleaseTools/)。

- `EnableHybridCLR` 不仅改宏，还可能自动安装 HybridCLR 与更新程序集设置，因此绝不能当作无害开关自动执行。
- `BuildAndCopyDlls` 在相应宏启用时编译热更 DLL 并复制为 `.dll.bytes`；AOT 元数据来自目标平台裁剪产物，没有真实构建产物就不能假装补充齐全。
- ReleaseTools 包含 AssetBundle、Windows、Android、iOS 和配置驱动构建入口；会写入文件、影响平台或触发真实构建，必须另获授权。
- 本地文件服务用于资源更新测试，不等于正式 CDN；不自行启动公网服务、上传或发布。

## HTML 转 UGUI

来源：[项目技能](../../UnityProject/.codex/skills/html-to-ugui/SKILL.md)、[实现目录](../../UnityProject/Assets/TEngine/Extension/HtmlToUGUI/)。

这是受约束的 UI-DSL，不是任意网页转换器：生成节点需 type/name，单命名根，图片采用允许的本地路径，不执行任意网页脚本，不联网拉资源，不把 CSS 字体自动转 TMP。

流程是 HTML 烘焙 JSON/截图 → 检查布局、图片、字体 → 预览 Prefab 与 importer/复制影响 → 明确授权 → apply → 资产验证、相关测试与多分辨率截图。

同路径覆盖保留 Prefab GUID 不等于保留手工修改或全部组件 fileID；不能据“生成成功”推断视觉验收通过。当前任务未执行此链路。
